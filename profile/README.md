## 🎯 Overview

This org covers **turning it into a company** — the operating knowledge technical founders need: how startups work as a system, customer discovery and product-market fit, go-to-market, finance and fundraising, operations and governance, and the endgame. Each curriculum is one self-contained repository, and you learn by building real **founder artifacts**, not reading case studies.

**At a glance:**

- 🏢 **8 curriculum repositories** (one self-contained repo per curriculum)
- 📚 **8 role tracks**
- 🧭 Start with **Startup Foundations**, then follow your role pathway

## 🧭 The Three-Axis Model

Startup knowledge is organized on three axes, not one — every module is tagged against all three. See **[startup-foundations](https://github.com/ai-startup-curriculum/startup-foundations)** for the canonical model.

1. **Functional curricula** — the deep bodies of knowledge, authored once (Foundations → Customer Discovery → PMF → GTM → Sales → Growth; Corporate Structure → Equity / Governance / Fundraising; Economics → Modeling / Runway / Unit Economics). See the [dependency graph](https://github.com/ai-startup-curriculum/startup-foundations/blob/main/FUNCTIONAL_CURRICULA.md).
2. **Role pathways** — curated views over the functional curricula (Founder/CEO, CTO, Product & GTM…), each declaring target coverage so a lesson is never rewritten six times.
3. **Startup stages** — `IDEA → PRE-SEED → SEED → SERIES-A → GROWTH → MATURE`, so the curriculum tells you what matters *now* and what to ignore. See [STARTUP_STAGES](https://github.com/ai-startup-curriculum/startup-foundations/blob/main/STARTUP_STAGES.md).

## 🚀 Quick Start

1. **Choose a track** from the table above, based on your experience and direction.
2. **Clone its repository:**

   ```bash
   git clone https://github.com/ai-startup-curriculum/startup-foundations.git
   cd startup-foundations
   ```

3. **Start with the first module** and read its `README.md`.
4. **Work through the exercises** in each module.
5. **Use the in-repo exemplars** to check your artifacts.

## 🧰 What You'll Build

- **Validation:** Customer-discovery interview plans, PMF measurement, ICP and positioning docs
- **Finance:** Runway models, three-statement and driver-based forecasts, unit-economics and cohort models
- **Equity & fundraising:** Cap tables, SAFE and convertible scenarios, investor funnels
- **Operations & governance:** Entity and founder agreements, equity-comp policy, board packets
- **Exit:** Deal-structure comparisons, LOI term reviews, diligence data rooms
